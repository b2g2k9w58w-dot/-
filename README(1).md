# 🤖 Automation Scripts

Коллекция скриптов для автоматизации повседневных задач.

## 📂 Содержание
- **File Organizer** — сортировка файлов по типам (изображения, документы, видео).
- **Clean Temp** — очистка временных файлов старше 7 дней.

## 🛠 Установка
1. Клонируйте репозиторий:
   `git clone https://github.com/ВАШ_НИК/automation-scripts.git`
2. Перейдите в папку:
   `cd automation-scripts`

## 📜 Скрипты

### File Organizer
Сортирует файлы в папке «Загрузки» по категориям.
**Запуск:** `python file_organizer/sort_files.py`

### Clean Temp
Удаляет временные файлы старше 7 дней (macOS/Linux).
**Запуск:** `bash system_utils/clean_temp.sh`
